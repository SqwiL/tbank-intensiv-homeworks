# T-Bank Intensiv Homeworks

Домашние задания Т-Интенсива по управлению рисками и кредитному скорингу. В ноутбуках собраны анализ данных, обучение моделей и эксперименты с оценкой кредитного риска и доходности.

## Ноутбуки

| Ноутбук | Описание |
| --- | --- |
| [ДЗ 2 — статистика и A/B-тестирование](2_lesson/dz-2.ipynb) | Исследование распределений выборочных статистик, оценка параметров методом максимального правдоподобия и сравнение теоретических доверительных интервалов с бутстрапом. В части про A/B-тестирование рассматриваются t-тест, достаточность размера выборки для заданного MDE, ошибка второго рода и распределение p-value в A/A-тестах. |
| [ДЗ 3 — логистическая регрессия](5_lesson/dz_3_klass.ipynb) | Расчёт WoE и IV, построение доверительных интервалов и проверка линейности признаков. Далее - анализ данных, кодирование категориальных переменных, преобразование числовых признаков и обучение логистической регрессии с оценкой ROC-AUC. |
| [ДЗ 4 — деревья и бустинг](6_lesson/dz_4_dereviannye_modeli.ipynb) | Подбор гиперпараметров LightGBM с помощью Optuna и оценка качества классификации по ROC-AUC. Интерпретация модели через SHAP помогает исследовать важность признаков, шумовые переменные и попарные взаимодействия. |
| [ДЗ 5 — отбор переменных](7_lesson/dz_5_otbor_peremennykh.ipynb) | Отбор признаков по IV, важности в бустинге и стабильности во времени, а также подготовка переменных для логистической регрессии. Реализован алгоритм Stepwise, исследуются качество итоговой модели и вклад признаков с помощью SHAP. |
| [ДЗ 6 — кредитные решения](8_lesson/dz-6.ipynb) | Построение модели вероятности дефолта с помощью LightGBM и подбор её параметров через Optuna. Решение об одобрении кредита принимается по ожидаемой прибыли с учётом кредитного лимита, дохода от надёжных клиентов и убытков при дефолте. |
| [ДЗ 7 — нейросети в скоринге](9_lesson/dz-7.ipynb) | Многопродуктовый кредитный скоринг по последовательностям транзакций с использованием LSTM. Проводятся эксперименты с признаками, архитектурой и функцией потерь; качество оценивается по гармоническому среднему ROC-AUC, а вклад признаков - через permutation importance. |
| [ДЗ 9 — поведение клиентов и NPV](11_lesson/dz-9.ipynb) | Анализ винтажей дефолта, сравнение скоров для разбиения клиентов на группы риска и сглаживание кривых DEF ratio с учётом внешних воздействий. Полученные кривые используются в NPV-модели для расчёта доходности кредита и исследования её зависимости от скора. |
